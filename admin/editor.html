Editorial workspace

Review and enhance movie metadata while preserving the original import. This editor works in your browser; it cannot directly publish changes or authenticate an administrator.

Local editing only. Changes remain in this browser until you export curated.json and commit the file at data/curated.json on the development branch. Do not include copyrighted descriptions you lack permission to use.

The exported file is checked by the repository's catalog tests. Only movie IDs already present in the catalog can be edited.
